# A two-chirality twistor correspondence for smooth Lorentzian Ricci-flat germs

Lior Isthmus · Version 1.1 · [ORCID](https://orcid.org/0009-0004-7908-9876)

Two ordinary cohomology classes on the flat hypersurface twistor CR space supply the free data for a smooth Lorentzian vacuum germ. The paper constructs its metric at physical scale and gives the inverse in terms of local comparisons of presentations. The wave kernel transports those comparisons between spacelike carriers.

[Paper (PDF)](paper/smooth-twistor-germs-en-v1.1.pdf) · [Markdown](paper/smooth-twistor-germs-en-v1.1.md) · [Standalone TeX](paper/smooth-twistor-germs-en-v1.1.tex) · [Changes](CHANGELOG.md)
